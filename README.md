# Onward App 🚀

**Onward** is a modern, task-oriented application designed to streamline workflows and boost productivity. Built with performance and user experience in mind, it provides a seamless interface for managing your daily goals.

## ✨ Features
- **Real-time Synchronization:** Powered by Supabase for instant data updates.
- **Modern UI/UX:** Clean, intuitive interface built with React and Tailwind CSS.
- **Responsive Design:** Optimized for both desktop and mobile devices.
- **Authentication:** Secure user login and registration system.

## 🛠️ Tech Stack
- **Frontend:** [React.js](https://reactjs.org/) with [Vite](https://vitejs.dev/)
- **Styling:** [Tailwind CSS](https://tailwindcss.com/) & [Shadcn UI](https://ui.shadcn.com/)
- **Backend/Database:** [Supabase](https://supabase.com/)
- **Icons:** [Lucide React](https://lucide.dev/)
- **Deployment:** [Vercel](https://vercel.com/)
